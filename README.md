# Mindthreads downloads

[Mindthreads](https://mindthreads.lemonberrylabs.com) is a free, keyboard-first Mac app that keeps track of everything you've started and haven't finished, so an interruption or a tangent doesn't make you lose it. It was built for people with ADHD, and for anyone whose attention gets split across too many things.

- Capture a thread from any app with ⌃⌥N, in about two seconds.
- Tangents become child threads, drawn as a graph.
- A thread's color warms the longer it goes untouched, and neglected threads pulse.
- Threads stay on your Mac in SQLite, or in your own Postgres database. No account.
- A built-in MCP server lets Claude Code, Cursor and other agents read and update your threads.

**Download:** [mindthreads.lemonberrylabs.com](https://mindthreads.lemonberrylabs.com), or [the latest build](https://github.com/lemonberrylabs/mindthreads-releases/releases/latest/download/Mindthreads.dmg) directly. Requires a Mac with Apple silicon and macOS 13.5 or later.

New to it? [How Mindthreads works](https://mindthreads.lemonberrylabs.com/guide) explains it in four steps.

This repository only holds release builds. Each successful build of Mindthreads is published here automatically.
