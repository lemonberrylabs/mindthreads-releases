# Mindthreads downloads

Mindthreads is a macOS app for keeping track of every thread of work you are holding in your head.

**Download:** [mindthreads.lemonberrylabs.com](https://mindthreads.lemonberrylabs.com), or [the latest build](https://github.com/lemonberrylabs/mindthreads-releases/releases/latest/download/Mindthreads.dmg) directly.

This repository only holds release builds. Each successful build of Mindthreads is published here automatically.
